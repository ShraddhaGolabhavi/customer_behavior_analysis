## 🔄 Project Steps

### 1. Data Loading

The dataset was loaded into Python using **Pandas** and initially inspected to understand its structure.

Activities included:

* Checking rows and columns
* Reviewing data types
* Identifying missing values
* Checking duplicate records
* Understanding categorical and numerical columns

### 2. Exploratory Data Analysis (EDA)

EDA was performed to understand patterns and relationships within the data.

Key activities:

* Descriptive statistics
* Distribution analysis
* Category-wise analysis
* Trend analysis
* Correlation analysis
* Identifying potential outliers

### 3. Data Cleaning

The dataset was cleaned and prepared for further analysis.

Steps included:

* Handling missing values
* Removing duplicate records
* Correcting data types
* Standardizing values
* Handling inconsistent data
* Preparing analysis-ready data

### 4. SQL Analysis

SQL was used to answer business questions and extract insights from the cleaned dataset.

Queries included concepts such as:

* `SELECT` and filtering
* `GROUP BY`
* `ORDER BY`
* Aggregate functions
* `JOIN`
* Subqueries
* `CASE WHEN`
* CTEs
* Window functions

The analysis was performed using **PostgreSQL / MySQL / SQL** depending on the analysis environment.

### 5. Power BI Dashboard

The cleaned data was used to create an interactive **Power BI dashboard**.

The dashboard includes:

* KPI cards
* Charts and visualizations
* Category analysis
* Trend analysis
* Filters and slicers
* Interactive business insights
